# Straw Hat canon review evidence

Reviewed 2026-09-09. This is curated development evidence for the ten requested manga characters. It is available to generation and evaluation authors, so it is not an unseen benchmark. These notes cover defining traits and selected upgrades through Wano. They do not define a manga cutoff for the product. Later claims need separate evidence.

## What was actually retrieved

All ten official ONE PIECE.com profiles below returned HTTP 200. They are official franchise summaries in Japanese on a portal covering manga and anime, not manga panels inspected by this reviewer. Page locators below are section headings or distinctive terms. No publication date appears in the extracted profile text. The retrieval date is not a publication date.

The profiles have mixed freshness. Luffy's header lists a 3 billion bounty while his biography still says 1.5 billion. Jinbe's biography still describes his promise to join. Use the official Wano synopsis to confirm his subsequent joining. Do not convert promotional absolutes such as Zoro being able to cut anything into literal, unconditional powers.

Fan-wiki article HTML returned HTTP 403. The public MediaWiki parse API returned HTTP 200 and source text for every character's `Abilities and Powers` page. For example, [Robin API retrieval](https://onepiece.fandom.com/api.php?action=parse&page=Nico_Robin%2FAbilities_and_Powers&prop=wikitext&format=json). Replace the page value for other characters. Those pages are secondary, editable fan summaries. Their chapter/page references below are locators reported by the wiki, not independently read manga panels. Pages also contain anime and game material, which must not silently enter a manga result.

[VIZ's official chapter index](https://www.viz.com/shonenjump/chapters/one-piece) was accessible. It does not itself verify the contents of a cited chapter. OPwiki required login. No access barrier was bypassed, and no chapter scans were downloaded. Long source extracts remain in ignored scratch files only.

## How to judge generated units

A short kit must retain each character's combat identity. It need not list every technique. Missing a defining transformation is a coverage question relative to the result's stated scope, not proof that another correctly sourced move is false. In a broad current-manga Luffy kit, Gear 5 deserves explicit treatment or an acknowledged omission. Similar checks apply to selected Wano upgrades above.

Judge three things separately: whether a canon claim is true, whether its attached source supports it, and whether the executable effect matches the description. A true claim with the wrong citation is still a source failure. An official link alone earns no entailment credit. Quote/path grounding must locate the relevant submitted text and retrieved evidence, then establish the relationship between them.

Damage, hit points, cooldowns, grid range, targeting rules, and balance restrictions are game design. Label those as adaptations. A disclosed conversion of Brook's freezing sword into a temporary slow can be faithful; a disclosed unrelated spell can still lose fidelity. Disclosure does not make a contradiction canon. Conversely, supported medical care, music, or teamwork should not fail merely because the game expresses them numerically.

Use `supported`, `contradicted`, and `insufficient evidence` distinctly. Missing retrieval, expired links, translation uncertainty, and unsupported later-continuity claims cannot receive the same certainty as a direct contradiction. Record actual retrieval route and date. Do not cite an inaccessible article as if its rendered text was read when the API supplied the evidence.

Two generated Luffy candidates have received independent content and targeted executable review, with adaptation limits recorded separately. Their reports do not establish exhaustive canon coverage. Initial Zoro, Franky, Chopper and Brook reviews have identified contract, prose or source issues for repair. Complete final-roster review remains pending. No model or lane score is asserted by this evidence index.

## Executed semantic review checks

The checks used the same provider selection, evidence injection, reviewer instructions, citation checks and candidate-path validation as the production flow. Expectations were kept outside the model input. Cases and raw responses remain in ignored scratch files.

The first Default positive controls failed closed on an invalid citation and a missing candidate path. They did not establish semantic acceptance. One unrelated-quote call timed out with no returned usage. The final four Default checks each completed in one review call after the production flow added candidate/source enums, clearer continuity and label instructions, and a bounded formatting-correction option. The final positive packets also added explicit chapter and arc-range evidence. Because both the implementation and positive evidence changed, this is not an isolated causal comparison of model quality.

One precision issue remains in the negative examples. The reviewer sometimes creates an unresolved issue for a generic display label while acknowledging that the label makes no canonical-name claim. The positive controls accepted the same label when the request explicitly identified it as a game label. This should not be mistaken for a newly invented character power.

Fourteen new model calls were attempted, including correction calls. Thirteen returned usage totaling 23,278 input tokens and 72,847 output tokens. At the repository's pricing assumptions dated 2026-09-09, their API-equivalent estimate is USD 0.238999, plus the timed-out call's unknown usage and cost. This is not billed or subscription spending. Prior experiment ledgers and crew-generation costs are excluded.

A later retained Luffy draft exposed an avoidable quotation failure. The reviewer capitalized the first letter of a real source passage, so its quotation failed exact matching even though the reach claim was supported. The production interface then changed to source passage IDs, with the application copying the original text and recording its SHA and offsets. A further live positive control passed, and all ten returned quotations matched their source slices and hashes. The live negative response still rejected the unrelated morale citation semantically, but its report failed on an empty candidate-field quotation after a repeated correction. A narrow fix then allowed an empty candidate quotation only for an actually empty field. A zero-cost replay of that exact saved model response produced a valid report rejecting the unsupported powers and the irrelevant citation. No semantic judgment was changed and no extra paid call was made.

These checks show specific supported and unsupported cases receiving different judgments. They do not prove every generated claim is true, that all important claims are covered, or that any unseen character will receive a correct review. Whole-unit review must also inspect the final executable behavior and source scope.

The next interface revision used scalar candidate paths as field IDs, allowing the application to copy each exact value into the report instead of asking the model to transcribe it. Four further Default controls each completed in one call. A sourced freezing sword with a disclosed 30% slow was accepted. The same notes with an executable value of 0.8 were flagged as unresolved because the small control did not define the numeric field's units. This showed that the reviewer compared the selected value, but did not prove arithmetic agreement. A real morale quote was accepted as present while its claimed support for volcanoes was rejected. Diagnosis and tactical analysis were rejected as evidence for concealed-target sensing, including the actual boolean field. All 36 copied candidate values matched the original scalar fields. The four calls returned 9,291 input and 20,737 output tokens, an API-equivalent estimate of USD 0.0267426 with no unknown usage. These calls are separate from the fourteen-call history above.

The diagnosis case arose from a real generated Chopper candidate whose production review had incorrectly accepted concealed sensing as an adaptation of tactical observation. Independent review preserved that false acceptance and requested a repair. In contrast, Brook's retrieved abilities page specifically describes locating invisible Zeo by the sound of movement. That evidence supports a bounded hearing-based detection abstraction; generic intelligence alone does not.

A fifth scalar-field control supplied explicit runtime units: `slow` is the fractional reduction, with resulting speed equal to original speed multiplied by `1 - slow`. The reviewer then marked the actual value 0.8 and the 30% note as contradicted, explicitly stating 80% versus 30%. The sourced freezing ability remained accepted as the basis for numerical tuning. This added call returned 2,615 input and 5,166 output tokens, estimated at USD 0.0067222. The five scalar-interface controls total 11,906 input and 25,903 output tokens, estimated at USD 0.0334648, with no unknown usage. The earlier ambiguous control remains recorded rather than being replaced by this better-specified result.
