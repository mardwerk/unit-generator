# Unit Generator

Unit Generator is an independently useful Tower Defense unit-content Tool.

It owns unit definitions, mechanic interpretation, source evidence and scoped unit validation. Its supported surfaces are an Engine, CLI and optional UnitLab in this repository. Each operation accepts explicit inputs and returns an inspectable Result; it can run without Towerright.

[Towerright](https://github.com/mardwerk/towerright) may provide curated Profiles, orchestrate Requests and retain accepted Revisions. Shared vocabulary lives in [Foundation](https://github.com/mardwerk/foundation).
