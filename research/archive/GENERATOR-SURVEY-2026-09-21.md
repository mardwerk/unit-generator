Archived source inspection, superseded as a research reading guide by the [current research index](../README.md). Card and monster generators offered implementation examples, but the later RTS-unit, Mortar, Mechanic Miner and GameASG-Bench papers address this project's representation and evaluation questions more directly. Public source inspection on September 21, 2026 found useful components, but no turnkey generator translating character canon into executable BTD6-style units with three five-tier paths. The repositories below were not installed or executed. Their descriptions do not establish generation quality, cost or interactive latency for this application.

[MTG AI Card Set Generator](https://github.com/maisogjm/mtg-ai-card-set-generator/tree/a07296767b6ea7283434c20a99437dbdecb1bc70), MIT, uses Pydantic structured output for themed, interacting card sets, including a Fantastic Four prompt example. Borrow its small schema and joint generation of related mechanics. Rules remain prose; name extraction, duplicate repair and explanation cleanup add model calls. Structural parsing does not validate interactions or balance.

[MtgCardsGenerator](https://github.com/januszek422/MtgCardsGenerator/tree/b82087dd6ae0bc2f65fbed9d08418943318f5939), MIT, supplies five existing cards matching the requested mana cost to one Groq Llama 3.3 70B call. Borrow budget-matched examples, extending selection to relevant roles. Its advertised balance is a prompt instruction, not an enforced check. It extracts JSON from text without a constrained response schema. The full .NET, database and artwork application is unnecessary here.

[ArthurG's statistical card generator](https://github.com/ArthurG-data/mtg-card-generator/tree/cba9c1245da9e45774542a98182cc6381c07fd98), MIT, samples stats from cost/rarity distributions and explores baseline stat budgets and keyword costs. Its `generation/validators.py` is empty. Borrow the comparison to established content, not its numerical coefficients or an assumption of tested balance.

[Monsterverse](https://github.com/abuzreq/dnd-ai-monsterverse/tree/95f4beb374d64229e5c251061f5efa8bc60af846) adapts existing D&D statblocks through Gemini, structured results and source context. Actions remain prose. No repository license was found. Its vector database, CLIP, LangChain agents and image generation are excessive for this request.

[GAVEL](https://github.com/gdrtodd/gavel), [NeurIPS 2024 paper](https://arxiv.org/abs/2407.09388), demonstrates model mutations of executable game descriptions followed by external evaluation. Its reported search takes roughly 48 hours for 4,500 samples, so it is offline research, not interactive generation evidence. No root license was found; the bundled Ludii fork uses CC BY-NC-ND 4.0. [FunSearch](https://github.com/google-deepmind/funsearch), [Nature paper](https://www.nature.com/articles/s41586-023-06924-6), similarly separates proposals from evaluation, but its reference implementation omits the model and execution sandbox. [XGrammar](https://github.com/mlc-ai/xgrammar), [technical report](https://arxiv.org/abs/2411.15100), constrains output syntax, not source fidelity or balance. These three were inspected on their main branches, without recorded commit pins.

Historical pipeline lesson: source packets are essential. A saved Rimuru failure exposed a deterministic selector defect: 86 of 96 passage slots were consumed by skill-list fragments, crowding out substantive behavior while using only 3,190 of 18,000 available characters. Retrieval had succeeded. A model comparison using that packet would confound pipeline failure with model capability. The [pipeline evaluation](../../docs/PIPELINE-EVALUATION.md) separates other observed runs and their limits.

The September 21 provisional direction was one compact generation call plus bounded, targeted repair, reusing the existing engine. This was a proposal, not an implemented default or the current concept-first roadmap. In that proposal, the model supplies source anchors, path identities and supported effect data; code validates structure, crosspaths, cumulative effects and arithmetic. Preserve meaningful source behavior; reject unsupported mappings rather than silently substituting generic stats. The discussed four-stage approach was also a proposal, not a committed replacement. Avoid adding vector retrieval, agents or evolutionary search wholesale.

Benchmark complete requests on fixed source packets and a separate fresh-retrieval set. Record total latency, billed tokens and cost including repairs, first-pass validity, omissions, character specificity, distinct path behavior, meaningful progression and human correction effort. Structural passes and arithmetic checks are not proof of enjoyable or balanced play. No arbitrary numerical balance rule follows from these sources.
