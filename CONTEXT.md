# Unit Generator context

Unit Generator owns unit-content meaning for Tower Defense games. Shared terms come from [Foundation](https://github.com/mardwerk/foundation).

- **Unit** — content describing a game actor or deployable combat element.
- **Mechanic** — a declared behavior that a Unit or related system exposes.
- **Unit Profile** — a tunable configuration of supported unit Definitions.
- **Unit Result** — generated or reviewed unit content with evidence, findings and outcome.

The Engine and CLI are standalone. UnitLab is a human surface over explicit Requests. Towerright owns project history, cross-tool orchestration and Acceptance; the generator owns unit computation and scoped validation.

Links: [Towerright](https://github.com/mardwerk/towerright), [Map Generator](https://github.com/mardwerk/map-generator), [Foundation](https://github.com/mardwerk/foundation).
